A deliberately simple baseline

LAS points → terrain correction → canopy heights → treetop peaks → watershed crowns → inventory

Uses supplied ground labels. Reference tree IDs are kept out of detection and used only for evaluation. The 2.5D canopy projection keeps computation simple but loses vertical forest structure.

What remains unresolved

Selected reserved-plot recall is 20.5%: 35 of 44 reference trees remain unmatched. This is a useful baseline with a demonstrated improvement; substantial segmentation work remains.

  • Canopy projection can merge neighbouring trees or miss suppressed crowns.
  • Ground classification is supplied; heights depend on the terrain estimate.
  • Height agreement is evaluated only for matched trees and is not independent field validation.
  • Two plots in one collection do not establish cross-site generalisation.
  • Analysis holds the selected plot in memory; scaling needs spatial tiling and reconciliation.
